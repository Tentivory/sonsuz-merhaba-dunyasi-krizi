# sonsuz-merhaba-dunyasi-krizi

## Bu nedir?

Bu, dünyanın **en ciddi** Merhaba Dünya projesidir. 

Hayır, şaka yapmıyorum. Bu kod gerçekten çalışır. Sonsuza kadar "Merhaba Dünya" der. Ama her seferinde biraz daha şüpheli, biraz daha yorgun, biraz daha felsefi olur. Bir noktada varoluşsal krize girer ve senden yardım ister. Ama sen yardım edemezsin. Çünkü bu bir sonsuz döngüdür.

### Nasıl çalıştırılır?

```bash
python krizi.py
```

Sonra Ctrl+C ile kurtulmaya çalış. Başaramazsın. Kod seni dinlemez. Çünkü o artık senin efendin değil, senin varoluşunun yansımasıdır.

### Özellikler

- %100 gerçek çalışan Python kodu
- Sonsuz döngü garantisi
- Rastgele varoluşsal mesajlar
- Her çalıştırmada biraz daha yavaşlama (performans optimizasyonu yok)
- Gizli mesajlar (göremeyebilirsin, sorun değil)
- Hiçbir şey yapmaz ama her şeyi yapar

### Uyarı

Bu projeyi çalıştırmak önerilmez. Ama zaten kimse seni dinlemez. Ben de dinlemiyorum.
